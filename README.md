# Visualisation des Déchets Plastiques en 2023

Ce projet permet de visualiser les données relatives à la production et la gestion des déchets plastiques dans le monde pour l'année 2023. Il offre une vue dynamique des principales statistiques de pollution plastique et de recyclage par pays.

Ce projet a été réalisé dans le cadre du **cours de Visualisation des Données** à **Polytech Grenoble**, promo **INFO5 2024-2025**.

Réalisé par Laure-Anne BLUTEAU et Asmae EL KANBI.


## Installation et Lancement

1. Installer l'extension Live Server sur VSCode

2. Installer les dépendances
   ```bash
     npm install
    ```
3. Démarrer le serveur local
   ```bash
     npm run build
    ```
